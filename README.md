# Async React Lab

Практическая работа №6: **Функции, модули, Promise и async/await**.

## Что отрабатывается

- Каррирование функций (`validateRange`, `validateMinLength`)
- ES-модули (`import` / `export`, `"type": "module"`)
- Параллельные комбинаторы промисов (`Promise.all` vs `Promise.allSettled`)
- Надёжные `async/await` сервисы с обработкой ошибок
- Отмена запросов через `AbortController` / `AbortSignal`
